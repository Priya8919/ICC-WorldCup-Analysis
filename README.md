🏏 ICC Cricket World Cup Data Analysis (1975–2023)
📘 Overview

This project provides a comprehensive data analysis of ICC Cricket World Cup tournaments, combining match, batting, bowling, and player data to uncover insights into performance trends, team dominance, and player consistency.

Through data cleaning, integration, and visualization, the notebook explores batting efficiency, bowling economy, and match outcomes across World Cup editions.

🧹 Data Preparation

Steps performed before analysis:

Loaded and merged all datasets.

Cleaned missing or inconsistent values.

Converted numeric and date types.

Derived new features (e.g., innings, batting order groups).

Integrated batting and bowling summaries for full player profiles.
